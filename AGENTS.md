# AGENTS.md — «Резюме-лендинг Андрея Краишкина»

Интерактивный лендинг-резюме для GitHub Pages. Один статический сайт, пять вариантов оформления, два языка (RU/EN). Читайте этот файл перед любой правкой.

## 1. Цель и аудитория

- **Кто смотрит:** executive-рекрутеры, собственники, HRD/CEO, советы директоров, кадровые службы корпораций и госструктур.
- **Что должны понять за 30 секунд:** это HR-руководитель, который строит функцию с нуля, снимает юридические риски и говорит с бизнесом на языке цифр.
- **Задача лендинга:** довести до контакта (Telegram, e-mail, звонок) или скачивания PDF.
- **Объём:** 3 экрана, не больше. Всё, что не помещается, уходит в раскрывающиеся блоки или PDF.

## 2. Позиционирование

- Заголовок: **HR-директор / CHRO**. Не «HRG», не «HR-менеджер», не «и.о.».
- Три опоры: **юридическая школа + 13 лет госслужбы + международный бизнес**.
- Формула каждого результата: ситуация → действие → цифра.
- Тон: спокойная уверенность, без самопохвалы и без канцелярита. Первое лицо допустимо в одном-двух местах (лид, CTA), дальше — безлично-деловой.
- Статус: «Открыт к предложениям». Период в ПАО «КИФА»: **январь 2025 — сентябрь 2026**.

## 6. Структура страницы

1. **Hero (100vh):** фото, имя, роль, лид (2–3 строки), теги отраслей, контакты, 4 KPI, CTA.
2. **Результаты:** 6 карточек с фильтром по категориям — эффективность / риски и комплаенс / масштаб и цифровизация.
3. **Опыт + компетенции:** таймлайн 6 ролей (все свёрнуты в `<details>`, кнопка «Развернуть все достижения» раскрывает сразу все), под ним — строка о личном ведении подбора, КДП, адаптации и обучения и три плашки: «Что умею», «Образование и квалификация», «О себе». Внутри плашек — полные списки навыков, дипломы, курсы, языки и текст «О себе».
4. **Футер-CTA:** «Обсудим вашу HR-задачу?», контакты, скачивание PDF, рекомендации по запросу.

Навигация: «Результаты», «Опыт», «Компетенции». Переключатель RU/EN в шапке, выбор в `localStorage`.

Варианты переключаются на одной странице (без отдельных файлов): `?theme=...` или плавающий переключатель. Ссылки для показа: `?theme=template`, `?theme=signal`, `?theme=onyx`, `?theme=onyx-steel`, `?theme=onyx-bordeaux`.

Правила:
- Текст меняется **только** в `assets/content.js`. В HTML — никаких захардкоженных фраз, кроме служебных.
- Новые стили — в тему, а не в разметку. Инлайн-стили запрещены.
- Не добавлять сборщики, фреймворки, CDN, внешние трекеры и шрифты с чужих серверов.

## 8. Пять вариантов оформления

Переключение: `?theme=template|signal|onyx|onyx-steel|onyx-bordeaux`, класс на `<body>`, выбор в `localStorage` (`ak_theme`).
Плавающий переключатель тем — только на период согласования; перед публикацией убрать (`SHOW_THEME_SWITCH` в `app.js`).

- **template** — ваш PPTX-шаблон, адаптированный под веб: Unbounded, лайм `#9ECF38` / `#EBF9C1`, розовый `#FF8FDA` / `#FFE4F6`, крупные скругления, пастельные панели.
- **signal** (по умолчанию) — тёмный executive-tech: фон `#0A0B0D`, лайм `#C9F24D`, стеклянные карточки, счётчики, дуотон на фото.
- **onyx** — та же тёмная вёрстка Signal, но графит `#0A0A0B` + медь `#C98A5B` / `#D8B48C`, без лайма.
- **onyx-steel** — графит `#0A0B0C` + сталь-синий `#7FA8C9` / `#A9C6DD`, CTA в глубоком синем `#24405A`.
- **onyx-bordeaux** — графит `#0B0A0B` + бордо `#C06474` / `#D8A3AC`, CTA в глубоком винном `#3A141C`.

Три onyx-варианта — оверрайды поверх signal: `body` получает классы `theme-signal theme-onyx*`, поэтому сетки, анимации и адаптив общие, меняется только палитра.

Общее: сетка 1200 px, воздух, крупная типографика, минимум декора. Анимации — 150–400 мс, только `transform`/`opacity`.

## 9. Правила кода

- Ванильный HTML/CSS/JS, без зависимостей. Работает при открытии с диска и на GitHub Pages.
- Семантика: один `<h1>`, `<section>` с `aria-labelledby`, `<ol>` для таймлайна, `<details>` для раскрытий.
- Доступность: контраст ≥ 4.5:1, видимый фокус, `aria-pressed` у переключателей, `prefers-reduced-motion` отключает анимации, ссылки-иконки имеют `aria-label`.
- Производительность: без блокирующих шрифтов, `loading="lazy"` для некритичных картинок, вес страницы до 600 КБ, Lighthouse ≥ 95 по всем осям.
- Адаптив: 360, 768, 1024, 1440. Мобильная версия — одна колонка, таймлайн без горизонтального скролла.
- Печать: `resume.html` укладывается в 3 страницы A4, чёрный текст на белом, ссылки видны.
- JS не должен ломать страницу без него: ключевой текст остаётся в `content.js`, но разметка секций — в HTML.
